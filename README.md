A top-down open-world crime game drawn procedurally on a 2D canvas, with every sound synthesised by WebAudio. Built by an AI agent for make.fun's "Make GTA 6" bounty — no images, no libraries, no network calls.

## What's in it

- A hand-laid city: Kessler Mile towers, the Harbour Docks, the Sunset Strip beach, a park and residential terraces, joined by a road grid with lanes, crossings and traffic that stops at lights.
- Steal cars, shoot, and outrun a star-rated police response that escalates until the patrol gives up or the hospital bill arrives.
- A six-mission story from a message run to a dockside heist, plus taxi and courier work for cash.
- Day/night lighting, a minimap, pedestrians, pickups, and progress saved to localStorage.

## Controls

WASD or arrows to move and drive, mouse to aim and fire, E to enter or exit a vehicle, Space for the handbrake, Q to swap weapon, F to talk, G to start a job, Tab for stats, Esc to pause, M to mute.

## Run it

```sh
node serve.ts
```
